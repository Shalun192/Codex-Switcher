# Codex Switcher Local 4.6.4

Version 4.6.4 is a bilingual local release for macOS and Windows.

## Highlights

- English is the default language, with complete EN/RU switching for the interface and all ten guides.
- Existing profiles from the earlier desktop build are detected and preserved during an update.
- Saved account authorizations remain encrypted through Keychain on macOS or DPAPI on Windows.
- Limit percentages, subscription labels, reset times, explicit connection, and optional auto-switching at 1% remain available.
- Removed profiles can still be restored locally.
- The public build has no custom backend, telemetry, or remote administration.
