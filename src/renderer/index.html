Instructions

Short answers about using Codex Switcher

1Quick start
  1. Click + and add a personal Free, Go, Plus, or Pro account.
  2. Complete the official OpenAI sign-in in your browser.
  3. Select the account you want from the list.
  4. Click Connect to Codex.
  5. Wait for the green dot and the “connected to Codex” label.
2How to add an account
  1. Click the + button in the upper-right corner.
  2. In the browser, sign in to the exact account you want to save.
  3. After sign-in succeeds, return to the Switcher. The account will appear in the list.
  4. Select it and click Connect to Codex.

The Switcher never requests or stores your password or two-factor authentication code.

3How to switch accounts
  1. Click the account you want once. Its row becomes selected.
  2. Click Connect to Codex. Selecting a row by itself does not change the Codex account.
  3. The Switcher fully closes Codex, atomically replaces local authorization, and starts Codex again.
  4. Wait for the “Account connected. Codex is running.” message.

The green dot marks the account currently connected to Codex.

4Limits and reset time

The percentage on the right is the remaining available limit. If two percentages are shown, they represent two different usage windows.

  • Green — enough capacity remains.
  • Orange — 50% or less remains.
  • Red — 20% or less remains.

The main limit window's reset time appears below the percentage. To check manually, select an account and click Refresh limits.

Auto-switch

  1. Enable the Auto-switch toggle on the main screen.
  2. While the Switcher is running, it checks the active account about once per minute.
  3. When either usage window reaches 1% or less, the Switcher checks following accounts in order and chooses the first one with more than 1% available.
  4. Codex is closed, the account is changed, and Codex starts again without another click.

If no account is available, the current account stays selected and the Switcher keeps checking. Disable the feature with the same toggle.

5How to update the app

Windows

  1. Open this GitHub repository's Releases page and download the new Windows build.
  2. Close the old Switcher.
  3. Extract the downloaded ZIP to a new folder and run Codex Switcher Local.exe.
  4. After verifying the new version, you may delete the old folder.

macOS

  1. Download the new DMG from Releases and close the Switcher.
  2. Open the DMG and move the app to Applications, replacing the old version.
  3. Start Codex Switcher again.

Saved accounts are stored separately from the application and are not deleted during a normal update.

6Removal and restoration
  1. Select an account and click Remove.
  2. Confirm the action. The account moves to a local archive.
  3. To undo an accidental removal, click Restore removed.

This does not delete the OpenAI account or cancel its subscription. The most recently removed local profile is restored.

7Errors and solutions

The connect button does not work

Solution: select an account row, confirm that sign-in completed, restart the Switcher, and try connecting again.

The account did not switch

Solution: after selecting an account, click Connect to Codex and wait for the automatic restart to finish. If the Switcher says it could not close Codex, close Codex manually and try again.

Auto-switch did not run

Solution: verify that the toggle is enabled, the Switcher is still running, at least two accounts are saved, and the next account shows more than 1% available. Click Refresh limits if a dash appears instead of a percentage.

Codex signed out

Solution: do not delete the Switcher or Codex data directories. Select the saved account and connect it again. If the OpenAI authorization expired, remove the local profile and add the account again through the official sign-in.

Limits are not displayed

Solution: check your internet connection, select the account, and click Refresh limits. If a dash remains, wait a few minutes; OpenAI may temporarily omit limit data. This does not prevent connecting the account.

The authorization window did not open

Solution: check the default browser and pop-up blocking, then click + again. If sign-in is already running, restart the Switcher and retry.

Protected storage is unavailable

Solution: unlock your macOS or Windows session and restart the app. The Switcher will not save new authorization data without Keychain or DPAPI.

Codex was not found

Solution: build the app using the standard README command, which downloads a verified official Codex binary. Also install the official Codex application on the computer.

The app closed unexpectedly

Solution: open the Switcher again and install the latest version from GitHub Releases. If the crash repeats, copy diagnostics and attach them to a bug report without authorization files.

8Security and privacy
  • Accounts are stored only locally; the app has no custom server or telemetry.
  • Saved authorization copies are encrypted through Keychain on macOS or DPAPI on Windows.
  • The official Codex process uses the network to sign in and retrieve limits directly from OpenAI.
  • Never send anyone your password, 2FA code, authorization files, or application data directory.
9Support and diagnostics

Diagnostics include only the app version, operating system, and auto-switch state. They do not contain account addresses, passwords, or tokens.

10New ChatGPT account and 2FA

Step 1. Prepare your information

  • Use an email address you can access permanently.
  • If you register with a password, create a unique password and save it in a password manager.
  • Install an authenticator app in advance, such as Google Authenticator, Microsoft Authenticator, Authy, 1Password, or another TOTP-compatible app.

Step 2. Create a ChatGPT account

  1. Click the button below or open chatgpt.com yourself.
  2. Select Sign up.
  3. Enter your email and create a password, or choose Continue with Google, Microsoft, or Apple.
  4. If OpenAI sends a message, open it and verify your email address.
  5. Complete the requested information and accept the service terms.
  6. After signing in, confirm that the normal ChatGPT screen opens.

Remember how you registered. If you used Google, Microsoft, or Apple, select the same sign-in method in the future.

Step 3. Open security settings

  1. In ChatGPT, click your profile icon.
  2. Open Settings.
  3. Go to Security.
  4. Find Multi-factor authentication (MFA) and select Authenticator app.
  5. Confirm your sign-in again if OpenAI asks.

Step 4. Obtain and store the 2FA secret

  1. OpenAI will show a QR code for configuring an authenticator app.
  2. If you need a text key, choose a link such as Can't scan it? or Enter setup key, if available.
  3. Copy the displayed TOTP secret only into a protected password-manager entry. Some interface versions show only a QR code; in that case, scan it directly.
  4. In the authenticator app, click +, scan the QR code, or choose manual entry and paste the key.
  5. The authenticator will generate a six-digit one-time code that changes about every 30 seconds.

Never enter the QR code or TOTP secret on another website or share it with anyone. Store it only in a trusted authenticator or password manager.

Step 5. Finish enabling 2FA

  1. Enter the current six-digit code from your authenticator in the ChatGPT window.
  2. Click Confirm or Continue.
  3. Verify that Authenticator app is shown as an enabled MFA method.
  4. If OpenAI displays recovery codes, save them in a separate protected entry.

Recovery codes are not the TOTP secret. Each recovery code is intended to restore access if the phone or authenticator is lost.

Step 6. Test sign-in

  1. Without signing out on your current device, open a private browser window.
  2. Sign in using the same method you used during registration.
  3. When ChatGPT requests the second factor, enter a new code from the authenticator.
  4. After successful verification, close the private window.

Step 7. Add the account to the Switcher

  1. Return to Codex Switcher and click +.
  2. Complete the official ChatGPT sign-in in your browser and enter the 2FA code yourself.
  3. Return to the Switcher, select the added account, and click Connect to Codex.

Do not store your password, QR code, TOTP secret, or recovery codes in unprotected notes, messages, or screenshots. If someone else learns the secret, disable that MFA method and configure it again.
