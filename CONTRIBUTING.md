# Contributing

1. Создайте отдельную ветку.
2. Не добавляйте реальные аккаунты, токены, email, IP, приватные URL, логи или собранные приложения.
3. Для тестов используйте только очевидно фиктивные значения домена `example.com`.
4. Выполните `pnpm run check` и `pnpm audit --audit-level high`.
5. Для изменений авторизации, IPC, запуска процессов или загрузки файлов обновите тесты и `THREAT_MODEL.md`.

Pull request должен кратко описывать изменение, риск и выполненные проверки.
