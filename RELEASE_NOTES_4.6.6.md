# Codex Switcher Local 4.6.6

Version 4.6.6 is a maintenance and release-integrity update for macOS and Windows.

## Highlights

- Removed an unused access-token freshness helper and an unreachable login-cancellation IPC route.
- Preserved the working login cleanup path, account switching, encrypted profiles, restoration, limit display, guides, and optional automatic switching at 1%.
- Synchronized the documented current version with the files published on the website and GitHub Releases.
- Reduced the public release to four useful assets; GitHub supplies its own source archives.
- Kept the editable SVG icon and historical release notes as useful project source and release history.

## Downloads

- `Codex-Switcher-4.6.6-mac-universal.dmg` — macOS 12+, Apple Silicon and Intel;
- `Codex-Switcher-4.6.6-win-x64.zip` — Windows 10/11 x64;
- `SHA256SUMS.txt` — SHA-256 checksums for the two application downloads and the file manifest;
- `FILE_MANIFEST_4.6.6.txt` — file-level SHA-256 manifest for tracked source and both unpacked applications.

Read `INSTALL.md` before installing. These builds are not signed with commercial Apple or Windows certificates, so the operating system may display a warning.
