# Codex Switcher Local 4.6.5

Version 4.6.5 is a synchronized maintenance release for macOS and Windows.

## Highlights

- English remains the default language with complete EN/RU localization.
- Existing encrypted local profiles remain preserved during updates.
- Limit percentages, plan labels, reset times, explicit connection, and optional switching at 1% remain available.
- The public build remains local-only and contains no private backend, device administration, telemetry, or remote control.
- Release packages are verified with both archive SHA-256 checksums and a file-level manifest.

## Downloads

- `Codex-Switcher-4.6.5-mac-universal.dmg` — macOS 12+, Apple Silicon and Intel;
- `Codex-Switcher-4.6.5-mac-universal.zip` — macOS application archive;
- `Codex-Switcher-4.6.5-win-x64.zip` — Windows 10/11 x64;
- `Codex-Switcher-4.6.5-source.zip` — prepared source archive;
- `SHA256SUMS.txt` — SHA-256 checksums for every release file;
- `FILE_MANIFEST_4.6.5.txt` — file-level SHA-256 manifest for the tracked source and both unpacked applications.

Read `INSTALL.md` before installing. These builds are not signed with commercial Apple or Windows certificates, so the operating system may display a warning.
